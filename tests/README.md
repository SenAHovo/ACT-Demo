# tests/ — 测试用例

## 测试分类

| 目录 | 测试范围 |
|---|---|
| `unit/` | 单元测试：各模块独立功能验证 |
| `integration/` | 集成测试：跨服务完整链路测试 |
| `compatibility/` | 兼容性测试：规范映射、字段对齐、命名空间验证 |
| `security/` | 安全测试：签名、凭证、密钥隔离、防重放 |

## 正常流程测试

- 身份、绑定和模拟子账户初始化成功
- 买卖双方完成本地身份鉴别和会话建立
- 三项服务全部购买，总支出0.90元
- 三个Artifact生成，三笔支付记录存在
- 各参与方保留原始存证记录
- DemoTrustService证据轨迹完整

## 异常测试覆盖

- **身份与绑定**：凭证过期/暂停/吊销、绑定失效、地址不一致、身份方案缺失
- **交互兼容**：缺少session_id、task_id不存在、message_id重放、发送方角色错误
- **授权**：IAC过期/暂停/吊销、智能体身份不匹配、非BOUNDED模式
- **预算与支付**：单笔超限、累计超限、余额不足、请求重放、幂等冲突、支付响应丢失、凭证篡改
- **Skill**：输入越界、Artifact摘要错误、DeepSeek不可用、角色级配置覆盖、模型调用失败后不重复购买
- **信任服务**：非法事件类型、act:误用、原始记录缺失、哈希被修改、上游引用缺失

## 运行方式

```bash
# 运行全部测试
pytest tests/

# 仅运行单元测试
pytest tests/unit/

# 运行带覆盖率报告
pytest tests/ --cov=. --cov-report=html
```
