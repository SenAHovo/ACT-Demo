## 核心设计

### 配置优先级
```
角色级配置 (BUYER_LLM_* / SELLER_LLM_*)
→ 全局配置 (DEEPSEEK_*)
→ 启动失败 (RuntimeError)
```

### 验证结果

1. **全局配置加载**: model=deepseek-v4-flash, url=https://api.deepseek.com OK
2. **买方角色级覆盖**: BUYER_LLM_MODEL=deepseek-v4-pro 覆盖全局 deepseek-v4-flash OK
3. **卖方角色级覆盖**: SELLER_LLM_API_KEY 覆盖全局密钥 OK
4. **继承全局**: 未覆盖字段自动继承全局值 OK
