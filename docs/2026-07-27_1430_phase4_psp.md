## API 端点

```text
GET  /schemas/local-balance-v1.json
GET  /v1/subaccounts/{sub_account_id}
POST /v1/payments
GET  /v1/payments/{out_trade_no}
POST /v1/payment-proofs/verify
POST /v1/trades/{trade_no}/fulfillment
GET  /health
```

## 支付处理流程（19 步）

```
1. 校验请求标识 → 2. 校验时间戳 → 3. 验证买方凭证
→ 4. 验证委托人-买方绑定 → 5. 验证支付绑定
→ 6-8. 验证 IAC（签名/状态/模式） → 9. 核验策略
→ 10. 单笔/累计金额 → 11. 资源绑定 → 12. 子账户
→ 13. 幂等检查 → 14. 事务扣款 → 15-16. trade_no+记录
→ 17. 签发凭证 → 18. 本地保存 → 19. 返回
```
