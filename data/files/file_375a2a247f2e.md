# Agentic Commerce Trust Protocol (ACT) Overview

## Background

As AI agents are widely adopted in commercial scenarios, the demand for autonomous transactions between agents is growing rapidly. ACT (Agentic Commerce Trust Protocol) is a trusted agent transaction protocol proposed by Alipay.

## Core Mechanisms

ACT defines four key domains for agent transactions:

1. **Delegation & Authorization Domain**: Users delegate agents to complete transactions via IAC (Intent Authorization Credential)
2. **Commerce Interaction Domain**: Buyer and seller agents engage in service discovery and negotiation through the A2A protocol
3. **Payment & Settlement Domain**: Implements conditional payments based on HTTP 402 and Payment Proof
4. **Trust & Notarization Domain**: The entire transaction process is recorded on-chain to ensure non-repudiation

## Typical Workflow

User delegates a buyer agent to procure services → Buyer agent discovers the seller's Skill catalog → Negotiate price and terms → Create IAC authorization → PSP executes payment → Seller delivers the service → Both parties confirm and notarize.
