# 智能体可信交易协议（ACT）概述

## 背景

随着 AI 智能体在商业场景中的广泛应用，智能体之间的自主交易需求日益增长。ACT（Agentic Commerce Trust Protocol）是由支付宝提出的智能体可信交易协议。

## 核心机制

ACT 定义了智能体交易的四个关键域：

1. **委托授权域**：用户通过 IAC（Intent Authorization Credential）委托智能体完成交易
2. **商业交互域**：买卖双方智能体通过 A2A 协议进行服务发现与协商
3. **支付结算域**：基于 HTTP 402 和 Payment Proof 实现条件支付
4. **信任存证域**：交易全流程上链存证，确保不可抵赖

## 典型流程

用户委托买方智能体采购服务 → 买方发现卖方 Skill 目录 → 协商价格与条款 → 创建 IAC 授权 → PSP 执行支付 → 卖方履约交付 → 双方存证确认。
