# Overview of Agentic Commerce Trust Protocol (ACT)

## Background

With the widespread adoption of AI agents in commercial scenarios, the demand for autonomous transactions between agents is growing rapidly. ACT (Agentic Commerce Trust Protocol) is a trusted agent transaction protocol proposed by Alipay.

## Core Mechanisms

ACT defines four key domains for agent transactions:

1. **Delegation and Authorization Domain**: Users delegate agents to complete transactions via IAC (Intent Authorization Credential)
2. **Commerce Interaction Domain**: Buyer and seller agents engage in service discovery and negotiation through the A2A protocol
3. **Payment and Settlement Domain**: Implements conditional payments based on HTTP 402 and Payment Proof
4. **Trust and Evidence Domain**: Records the entire transaction process on-chain to ensure non-repudiation.

## Typical Flow

The user delegates a buyer agent to procure services → The buyer agent discovers the seller's Skill catalog → Negotiates price and terms → Creates an IAC authorization → The PSP executes payment → The seller fulfills and delivers → Both parties confirm and record evidence.
