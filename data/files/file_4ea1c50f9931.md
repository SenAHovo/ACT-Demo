## 城市基本信息

- **气候与最佳季节：**
  - **气候类型：** 亚热带季风气候，四季分明。
  - **最佳季节：** **春季（3-5月）** 和 **秋季（9-11月）**。此时天气温和，景色宜人，尤其是春日柳绿花红和秋日满城桂花香。
  - **夏冬提醒：** 夏季（6-8月）炎热潮湿，常有雷阵雨，并被戏称为“蒸笼”；冬季（12-2月）湿冷，体感温度很低，且可能没有暖气。
- **市内交通：**
  - **地铁：** 杭州地铁网络非常发达，覆盖了西湖、高铁站、机场及主要商业区。用 **支付宝** 的“出行”功能直接扫码乘车，无需买票，非常方便。
  - **公交：** 同样可用支付宝乘车码。但容易堵车，建议优先选择地铁。
  - **出租车/网约车：** 滴滴等平台很普及。注意避开早晚高峰和西湖周边拥堵路段。
  - **共享单车：** 骑行是游览西湖周边的最佳方式之一，随扫随走。

## 特色景点推荐

1.  **西湖风景名胜区：**
    - **时长：** 至少半天到一整天。

    - **特点：** 杭州灵魂。可步行、骑行、乘船游览。推荐断桥残雪、白堤、苏堤、花港观鱼。
2.  **灵隐寺：**
    - **时长：** 2-3小时。
    - **门票：** 飞来峰景区门票**¥45** + 灵隐寺香花券**¥30**。
    - **特点：** 千年古刹，中国佛教禅宗十大古刹之一。环境清幽，感受禅意。
3.  **雷峰塔：**
    - **时长：** 1小时。
    - **门票：** **¥40**。
    - **特点：** 观赏西湖全景和落日的最佳地点之一。塔内有电梯和扶梯，轻松登顶。
4.  **西溪国家湿地公园：**
    - **时长：** 3-4小时。
    - **门票：** **¥80** (门票+船票套餐更划算)。
    - **特点：** “城市里的湿地”，乘船穿行于水网密布的村落和芦苇荡中，体验自然野趣。
5.  **清河坊历史街区：**
    - **时长：** 1-2小时。
    - **门票：** 免费。
    - **特点：** 步行街，保留了大量清末民初的杭州老建筑，可品尝小吃、购买特产。
6.  **龙井村 / 梅家坞茶文化村：**
    - **时长：** 2-3小时。
    - **门票：** 免费。
    - **特点：** 西湖龙井原产地之一。可体验采茶、品茶、吃农家饭，风景优美。
7.  **浙江大学（之江校区）：**
    - **时长：** 1-2小时。
    - **门票：** 免费，需提前预约。
    - **特点：** 百年老校区，保留了大量民国时期的老建筑，被誉为杭州最美的校园之一。游客相对较少。
8.  **京杭大运河（杭州段）：**
    - **时长：** 1-2小时。
    - **门票：** 游船费用约 **¥50-¥100**。
    - **特点：** 可乘坐水上巴士，体验流动的历史。小河直街、拱宸桥一带很有老杭州生活气息。

## 文化与风俗

- **茶文化：** 杭州是龙井茶的故乡。在龙井村或梅家坞品茶，是体验杭州慢生活的重要一环。给长辈带伴手礼，龙井茶是上选。
- **赏桂：** 秋季（9-10月）满城桂花香，全城公园，尤其是满陇桂雨公园会举办赏桂活动。
- **断桥残雪：** 是有名的西湖十景之一，冬季下雪后可一睹“断桥不断”的奇特景象。
- **西湖传说：** 白娘子和许仙的爱情故事深入人心，许多景点如雷峰塔、断桥都与这个传说有关。
- **市花/市树：** 市花是桂花，市树是樟树。

## 历史背景

杭州历史悠久，是中国七大古都之一。
- **秦朝设县：** 钱唐县，是杭州最早的建制。
- **隋唐时期：** 开凿京杭大运河，奠定杭州的江南重镇地位，白居易任杭州刺史时疏浚西湖。
- **南宋时期：** 1127-1279年，宋高宗定都杭州（时称临安府），成为当时世界上最繁华的城市之一。可以说，南宋是杭州历史上最辉煌的篇章。
- **近代以来：** 杭州成为了著名的风景旅游城市，西湖文化景观在2011年被列入世界文化遗产。

## 安全与应急

- **治安情况：** 杭州作为省会城市，社会治安非常好，属于全国最安全的城市之一。在夜间游客较多区域，您完全可以放心出行。
- **小提醒：** 在西湖边或繁华商业区，仍需看管好个人财物，谨防小偷。
- **紧急电话：**
  - 报警：**110** (短信报警：12110)
  - 急救：**120**
  - 火警：**119**
- **使领馆：** 杭州是**中国**城市，没有外国使领馆。如需帮助，请联系当地派出所或拨打110报警电话。
- **重要地址信息：** 出发前，请将酒店名称、地址和联系电话，以及家人或紧急联系人的电话号码，用笔记在纸上或存为手机备忘录。
