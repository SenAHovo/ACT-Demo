# エージェント信頼取引プロトコル（ACT）概要

## 背景

AIエージェントがビジネスシーンで広く活用されるにつれ、エージェント間の自律的な取引ニーズが高まっています。ACT（Agentic Commerce Trust Protocol）は、Alipayが提唱するエージェント向け信頼取引プロトコルです。

## 中核メカニズム

ACTはエージェント取引における4つの主要ドメインを定義します。

1. **委任認可ドメイン**：ユーザーはIAC（Intent Authorization Credential）を通じてエージェントに取引を委任します
2. **商業インタラクションドメイン**：売り手と買い手のエージェントがA2Aプロトコルを介してサービス検出と交渉を行います
3. **決済清算ドメイン**：HTTP 402およびPayment Proofに基づく条件付き支払いを実現します
4. **信頼証跡ドメイン**：取引の全プロセスをブロックチェーンに記録し、否認防止を確保します

## 標準フロー

ユーザーが買い手エージェントにサービス調達を委託 → 買い手が売り手のSkillカタログを発見 → 価格と条件を交渉 → IAC認可を作成 → PSPが支払いを実行 → 売り手が履行・納品 → 両者が証跡を確認・保存
