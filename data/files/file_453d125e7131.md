# Overview of Agentic Commerce Trust Protocol (ACT)

## Background

With the widespread adoption of AI agents in commercial scenarios, the demand for autonomous transactions between agents is growing rapidly. ACT (Agentic Commerce Trust Protocol) is a trusted transaction protocol proposed by Alipay for agent-to-agent commerce.

## Core Mechanisms

ACT defines four key domains for agent transactions:

1. **Delegation and Authorization Domain**: Users delegate agents to complete transactions via IAC (Intent Authorization Credential).
2. **Commercial Interaction Domain**: Buyer and seller agents discover services and negotiate through the A2A protocol.
3. **Payment and Settlement Domain**: Conditional payments are implemented based on HTTP 402 and Payment Proof.
4. **Trust and Evidence Domain**: The entire transaction flow is recorded on-chain to ensure non-repudiation.

## Typical Flow

User delegates the buyer agent to procure services → Buyer agent discovers the seller’s Skill catalog → Negotiate price and terms → Create IAC authorization → PSP executes payment → Seller fulfills and delivers → Both parties confirm and store evidence on-chain.
