# エージェント信頼取引プロトコル（ACT）概要

## 背景

AIエージェントがビジネスシーンで広く活用されるにつれ、エージェント同士の自律的な取引需要が高まっています。ACT（Agentic Commerce Trust Protocol）は、支付宝（アリペイ）が提案するエージェント向け信頼取引プロトコルです。

## 中核メカニズム

ACTは、エージェント取引における4つの主要ドメインを定義します。

1. **委任承認ドメイン**：ユーザーはIAC（Intent Authorization Credential）を通じてエージェントに取引を委任します
2. **商取引インタラクションドメイン**：売り手と買い手のエージェントがA2Aプロトコルを介してサービス発見と交渉を行います
3. **決済ドメイン**：HTTP 402およびPayment Proofに基づき条件付き支払いを実現します
4. **トラスト証明ドメイン**：取引の全プロセスをチェーン上に記録し、否認防止を確保します

## 標準フロー

ユーザーが買い手エージェントにサービス調達を委託 → 買い手が売り手のSkillカタログを発見 → 価格と条件を交渉 → IAC認証を作成 → PSPが支払いを実行 → 売り手が履行・納品 → 両者が証明を記録して確認。
